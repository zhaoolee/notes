## 架构事实

- 前端源码当前位于 `src`，后端源码当前位于 `server`。
- `NoteSheet` 和 Markdown 分段逻辑由前端预览、Playwright PNG 导出和离线归档共同复用。
- PNG 导出依赖 Playwright Chromium 打开可访问的前端页面。
- 单容器镜像由 Express 提供前端静态文件；双容器生产环境由 Nginx 代理 API 和图片。
- `storage/images` 是导入图片与已生成 PNG 的持久化边界。
- 项目当前没有数据库、账号系统或鉴权层。

## 2026-07-26：Markdown 视觉兼容性测试

- 可重复使用的测试数据位于 `frontend/tests/markdown-support-visual.md`。
- 自动语义测试位于 `frontend/tests/markdown-support.test.ts`。

- `##` 是项目的便签区段分隔符，不按标准 H2 内容渲染。
- 单个软换行会被项目插件拆成手动换行段落，和 CommonMark 默认行为不同。
- 原始 HTML 不会生成 HTML 元素，而是按字面文本显示。
- 任务列表同时显示列表圆点和复选框。
- 默认主题下链接对纸张背景的对比度约为 2.93:1，引用文字约为 1.97:1。
- 脚注功能可用，但 `Footnotes` 辅助标题因缺少隐藏样式而可见。

## 2026-07-26：本地多便签工作区

- 前端状态包含便签集合和当前便签 ID，每张便签独立保存 Markdown、创建时间和更新时间。
- 工作区使用 `notes.workspace.v1` 持久化到浏览器 `localStorage`；旧的 `notes.markdownDraft` 会在首次加载时迁移为第一张便签。
- 大于 `640px` 时使用常驻左侧栏，提供搜索、新建、切换和带确认的删除；项目不再保留中间宽度的平板抽屉布局。
- 侧栏只显示更新时间和从 Markdown 自动提取的标题或第一句话；列表采用 50px 行高、20px 左留白、12px 时间和 14px 标题。选中项仅使用浅背景与单层内阴影，不显示左侧色条或额外顶线。
- 删除最后一张便签时会自动创建新的空白便签，工作区始终至少保留一张。
- 存图、归档、复制和插图都只作用于当前选中的便签；示例内容只用于首次初始化，不再作为正式界面操作。
- 当前多便签数据只存于浏览器本地，不包含账号同步或服务端数据库。
- 前端 feedback 覆盖工作区数据校验、标题摘要提取和侧栏结构；浏览器验收确认新建、切换、刷新持久化、搜索与删除流程可用。

## 2026-07-26：notes-export-api Skill 端到端验证

- 已安装的 `notes-export-api` Skill 可调用当前服务完成默认主题、`smartisan-dark` 主题和本地图片 Markdown 导出。
