  网页地址交给原生 textarea 按正文插入。
- 纯文本图片地址的快速判定集中在 `isLikelyImageUrl()`，扩展名与后端当前支持的
  `png/jpg/jpeg/gif/webp/bmp/svg` 保持一致；富文本 `<img>` 仍可导入没有扩展名的
  图片 CDN 地址。

## 2026-08-05：宣传截图制作页

- `/promo/editor` 与 `/promo/pages` 分别提供“单图聚焦”和“多页层叠”宣传图制作，
  两页都固定在前端 Canvas 中按 `2048 × 920` 像素绘制并用 `canvas.toBlob()` 下载
  PNG，不依赖后端，也不会持久化或上传用户图片。背景色同时支持颜色选择器和六位
  十六进制文本输入（带或不带 `#`），只有完整合法值才更新 Canvas，失焦时无效输入
  恢复为上一个有效颜色。
- 单图模板读取一张 PNG、JPG 或 WebP，按画框宽度等比缩放，始终完整保留原图宽度
  并从顶部开始绘制。长图只裁切纵向内容，可用 `0%–100%` 滑杆从顶部连续移动到
  底部；高度不足的图片锚定顶部，剩余区域保持白色。左侧背景使用
  `public/promo-script-texture.png` 的透明手写纹理重复铺放，纹理
  和右下角长笔画均直接绘入 Canvas，保证预览与下载 PNG 一致，加载失败时使用简化
  曲线回退。多页模板最多读取三张图片，第一张始终放在最前层，后两张依次向后层叠。
  多页默认使用 `contain` 保留整张图片，空余区域显示白色；需要铺满纸张时可手动
  切换为 `cover`。多页模式按仿射变换后纸张水平、垂直向量的真实长度计算取景，
  不能使用变换前的竖向逻辑尺寸，否则跟随第一张图生成的横向纸张会把横图裁成
  竖条。`cover` 默认从原图顶部开始取景，前、中、后三层图片分别用独立的
  `0%–100%` 滑杆移动到原图底部，方便用户逐张定位长图内容；未上传层级保持禁用，
  `contain` 不应用这些位移。图片可通过“前移 / 后移”在前、中、后三层之间重排，
  重排必须同时移动图片来源、文件名、已加载图片和该图片自己的纵向取景位置。三层纸张
  共用 `60%–140%` 的宽度和
