让锤子便签面向互联网广播

2026-11-20 软件

我在 github 维护锤子便签的开源版，https://github.com/zhaoolee/notes 目前已经获得335个star

产品痛点：

局域网的局限，我用AI从v2ex，hacker news获取一手的言论与新闻，用skill存储到锤子便签，通过公众号和朋友们分享，但公众号是一个封闭的生态，无法被互联网索引

独立站高成本，我尝试把锤子便签发布到个人站，但是服务器的成本只增不降，白嫖小主机，年年搬家，维护起来相当麻烦

解决方案

我在开源版锤子便签，添加了发布为静态站的功能，配置完成后直接发布到github pages空间，白嫖github pages无限流量，建立维护成本为0的品牌博客站！只要微软不倒闭，github pages就是稳定的。
