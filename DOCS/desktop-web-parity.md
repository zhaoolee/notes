# 锤子便签网页版桌面对标基线

## 参考环境

- 页面：<https://yun.smartisan.com/#/notes>
- 核对日期：2026-07-27
- 核对视口：`1596 × 1195`
- 数据来源：用户已登录的官方锤子便签网页版

## 桌面布局基线

| 区域 | 官方尺寸或位置 | 项目实现 |
| --- | --- | --- |
| 顶栏 | `62px` 高 | `--topbar-height: 62px` |
| 分类栏 | `251px` 宽 | `15.72vw`，1596px 视口下约 251px |
| 便签列表 | 约 `414px` 宽 | `25.95vw`，1596px 视口下约 414px |
| 正文工作区起点 | `x = 665px` | 1596px 视口下约 `x = 665px` |
| 分类搜索框 | `230 × 29px` | 左右各 10px、29px 高 |
| 单条便签 | `50px` 高 | `50px` 高 |
| 状态栏 | `50px` 高 | `50px` 高 |
| 分类栏底部账号区 | 原下载区为 `50px` 高 | `50px` 高，承载登录或当前账号 |
| 便签栏底部折叠区 | `50px` 高 | `50px` 高，按钮距左 `20px` |
| 模式按钮 | `125 × 24px` | `125 × 24px` |
| 顶栏大按钮 | `68 × 38px` | `68 × 38px` |

便签列表必须从顶栏下方 `y = 62px` 直接开始，不保留额外的分类选择标题行。分类选择常驻在最左列，正文区左侧保留 25px 纸张装订边。

## 桌面字体渲染

- 官方页面和项目都优先使用 `PingFang SC`，顶栏、分类、列表时间和列表标题的计算字重均为 `400`。
- 官方页面使用浏览器默认的 `text-rendering: auto` 和 `-webkit-font-smoothing: auto`。项目 PC 端必须保持相同设置；强制使用 `antialiased` 会在 macOS Chrome 中削薄中文笔画。
- 该覆盖只作用于大于 `640px` 的普通 Web 工作区，不改变移动版，也不改变 Playwright PNG 导出模式。

## 顶栏操作

桌面顶栏按官方位置分组：

- 左侧标题区：菜单、锤子便签。
- 便签列表右侧：刷新、新建。
- 正文区左侧：插入图片、转移文件夹。
- 正文区右侧：分享、删除。

项目额外的账号入口放在分类栏左下角，替换原“下载锤子便签 APP”区域，不能挤压
刷新 / 新建工具组或覆盖便签列表。未登录时显示“登录锤子便签”，登录后显示当前
用户名；账号菜单向上展开并限制在分类栏宽度内。分类栏收起时账号入口一起隐藏，
重新展开后恢复。普通用户的账号菜单同时提供“修改密码”和“退出登录”；管理员
会话显示云同步状态，并提供管理后台入口与退出；管理员便签使用独立云端工作区，
但不允许在页面中修改服务端环境变量里的管理员密码。菜单采用紧凑的无外框操作
行，长邮箱必须单行省略，不能撑破分类栏。

分类栏底部右侧保留 `50px` 宽设置入口，与左侧账号区组成同一条 `50px` 底栏。
按钮复用移动端齿轮资源，暖白主题使用棕灰图标，暗黑主题使用 APK 暗色资源。
点击后从左下角向上展开唯一的 `SettingsPanel` 实例，功能与移动端完全一致：
账号与同步状态、登录 / 修改密码 / 退出、背景主题切换，以及“便签底部文字”。
底部文字二级页包含带双框和四角小格的实时便签预览、可上传替换的 Logo、
可编辑的发送来源与 `via` 文本和恢复默认按钮；桌面与手机共享同一份持久化设置。
弹层固定在 `left: 10px; bottom: 58px`，点击外部或按 Escape 关闭；收起分类栏
时一并关闭。

桌面顶栏不显示移动版设置齿轮和“存图”文字按钮；设置入口只放在分类栏底部，
存图、复制和归档由分享面板继续承接。转移按钮打开 `600px` 宽的“转移至其他文件夹”对话框。

点击刷新时，按钮中的刷新 Sprite 先顺时针旋转一圈，再重载当前工作区；旋转期间
忽略重复点击。这样既保留官方网页版的动作反馈，也确保重载发生前动画能够完整
呈现。

## 编辑与预览

桌面工作区默认只显示 Markdown 编辑器。点击“Markdown 模式”右侧三角会打开锚定在按钮下方的白色浮窗，浮窗为 `202 × 110px`、圆角 `5px`、使用细边框和轻阴影；项目只有 Markdown 与实时预览两种模式，因此两行各占 `52px`，避免第二行底部点击区过短。选择“实时预览”后互斥显示预览工作区。

便签列表不提供逐行悬浮删除叉号；普通便签只通过右上角红色垃圾桶删除当前选中项。回收站内部仍保留“恢复 / 永久删除”专用操作。

编辑器左侧 `25px` 纸轨和正文共用 `50px` 横线周期。正文滚动时，正文横线必须
使用 `background-attachment: local` 跟随 textarea 内容，纸轨背景纵坐标同时
同步为正文滚动容器的负 `scrollTop`，并写到拥有纸轨伪元素的
`.markdown-editor-frame`；不能把变量只写在其后代滚动容器上。任意滚动位置下，正文
文字、正文横线和纸轨横线都应保持同一相位。默认暖白纸面和锤子暗黑纸面遵守
相同规则，主题的 `background` 简写不能重置这项滚动属性。

分段 textarea 按内容自动调整高度时会临时把高度设为 `0`。调整前必须保存正文
滚动容器的 `scrollTop`，全部高度恢复后立即写回，否则在第七行等视口下方输入时，
浏览器会因内容瞬时收缩把滚动位置钳制为 `0`，造成编辑焦点看起来强制跳回顶部。

实时预览把 `##` 分段标题输出为语义化 `h2`，字号和字重都高于正文。标题以
`1.`、`2.` 等数字开头时仍是标题文本，不能再次被 Markdown 渲染器误判为有序列表；
标题内部的粗体、斜体和链接等行内 Markdown 继续生效。

H2 还必须遵守靠近性：标题与上一段之间使用 `18px × note-scale` 的上间距，
与自己正文之间只保留 `6px × note-scale`。`splitSections` 在 H2 边界丢弃上一节
末尾和标题后紧邻的 Markdown 空行，避免这些空行把视觉关系反转成“上窄下宽”。

文档顶部的居中 H1 是整张便签的唯一主标题，间距方向与 H2 不同：它靠近上方纸框，
并与后续正文留出略大的间隔。`NoteSheet` 只识别第一个居中 `#` 标题为文档标题，
使用 `-24px × note-scale` 抵消通用纸面顶部留白，并在标题下保留
`10px × note-scale`；普通 `[居中正文]` 不继承这组间距。

桌面实时预览和整页分享预览都支持按 `Escape` 返回 Markdown 编辑。对话框、设置、
菜单或移动面板打开时仍由对应浮层优先处理 Escape，不能越过浮层直接切换正文模式。

## 状态栏与专注编辑

- 状态栏文件夹选择器左侧使用官方 `24 × 24px` 文件夹 Sprite，右侧保留展开三角。
- 字数右侧使用官方 `24 × 24px` 写作模式 Sprite；点击后强制回到 Markdown 编辑，
  隐藏分类栏、便签列表和棕色桌面顶栏，但不能把纸张拉伸到整个屏幕。状态栏与编辑
  纸最大宽度为 `1120px` 并水平居中，左右继续露出同一张官方木纹背景。
- 专注状态左侧返回按钮为 `44 × 34px`，内部使用 `3px` 粗、`10px` 边长的短折线箭头；
  右侧展开按钮也可再次点击退出。即使 textarea 仍有焦点，按 `Escape` 也必须退出
  专注编辑并恢复进入前的桌面布局。
- 该状态只改变 PC 布局，不修改当前便签或分类折叠偏好；`640px` 及以下移动断点不
  显示专注入口，继续使用列表、编辑、预览三态工作区。

## 桌面暗黑主题

桌面暗黑主题沿用安卓锤子便签 `4.2.1` 的中性暖黑色板，但继续保留网页版的三栏比例、`50px` 正文行距和桌面工具栏密度，不把移动端列表卡片结构搬到 PC：

- 分类栏、便签栏、正文工具栏和面板统一使用 `#1e1c1e`，避免出现“暗黑外壳包着白色编辑器”。
- 编辑纸面和实时预览使用 `#1c1a1c`，左侧纸轨使用 `#161416`，横线与分栏线使用 `#282828`。
- 正文和列表主标题使用 `#cecece`，时间、字数及次级状态使用 `#676467`。
- Markdown / 实时预览菜单、账号入口、搜索框和底栏都必须使用同一套暗色表面；桌面顶栏保留锤子木纹质感，但降低棕色偏色并保证白色图标对比度。
- 顶栏的刷新、新建、AI、插图、转移、分享和删除七个操作按钮在暗黑模式下必须
  统一使用 `#3a363a → #2b282b` 深灰渐变、`#4a464a` 边框与同一组内外阴影；
  AI、插图、转移、分享和删除不能继续使用暖棕、荧光绿或红色按钮底。悬浮和分享
  展开态统一切换为 `#454045 → #343034`。

## 底部栏与分类折叠

- 分类栏和便签列表底部都固定保留 `50px` 操作区，背景为 `#fbf7ed`，顶部细线为 `1px #e9dece`。
- 分类栏底部使用原下载区的 `50px` 高度显示账号入口，文字为
  `12px #9d8369`；未登录时点击打开登录弹窗，登录后点击打开向上的账号菜单。
- 便签列表底部折叠按钮使用官方 Sprite 坐标：展开三栏时为 `-287px -220px`，收起分类栏后为 `-247px -220px`。
- 收起分类栏只改变桌面网格：分类栏宽度变为 `0`，便签列表移动至 `x = 0`，正文区紧跟便签列表；再次点击恢复原三栏，不改变当前便签或滚动内容。

## 分享预览

桌面点击分享后进入官方同类的整页分享预览，而不是弹出普通下拉菜单：

- 顶栏正文区左侧显示 `66 × 38px` 的取消按钮，右侧显示复制、归档和保存图片；项目保留真实已有能力，不伪造未实现的微博分享。
- 正文工具栏和编辑器暂时隐藏，右侧预览从顶栏下方 `y = 62px` 开始铺满。
- 木纹舞台顶部留白 `20px`，`660px` 宽便签纸居中；在 `1596px` 视口下纸张左边约为 `x = 800.5px`。
- 取消分享后恢复进入分享前的 Markdown 编辑或实时预览模式。
